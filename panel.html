Share with Pi

Inspect elements in the DOM tree to collect steps in this sidebar. Recording starts when this interface loads and continues if you switch to another sidebar or DevTools tab. Actual clicks are not recorded.

Localhost:8080 only. Form values and common secret attributes are omitted, but page text, URLs, and HTML can still contain private data. Review before saving. Steps stay in memory until you save. Closing DevTools or reloading the extension loses unsaved steps. Nothing is sent to Pi automatically.
